# 设计：手机 app 的界面（照 T3 Code 的手机端）

**状态：设计已定，未开始。** 方案见 [phone.md](phone.md)；可点的样稿在
[phone-ui.html](phone-ui.html)（浏览器打开，右上角切深浅色）。

依据：T3 Code `c7157d37` 的 `apps/mobile`（`generated-uniwind-default-theme-variables.json`、
`lib/typography.ts`、`designTokens.ts`、`thread-list-v2-items.tsx`、
`ThreadFeed.tsx`、`PendingApprovalCard.tsx`、`ThreadComposer.tsx`、
`nativeReviewDiffAdapter.ts`、`ConnectionsNewRouteScreen.tsx`），pansy 窗口的
`desktop/nsh.json` 主题，NSH 0.6.1 的 `NavStack`、`Sheet`、`TabBar`。

## 原则

1. **长得像 T3。** 几乎单色：锌灰的底，一种强调色；列表像"信息"和"邮件"，
   平铺、内缩的细分隔线、不套卡片；只有用户的话是气泡，agent 的回答平铺在
   画布上；浮起来的东西（输入框、状态胶囊、筛选、提示）是半透明毛玻璃。
2. **颜色只给状态。** 状态是 13pt 加粗的小字加一个图标，不是色块、不是角标。
3. **安静地显示在忙。** 进行中的行淡到 55%，正在跑的工具行有一道扫光，流式
   输出时轻触感。
4. **pansy 多出来的地方用 pansy 的样子。** 模型选择里有 pansy 的 provider 和
   路由组；品牌色是 pansy 的靛蓝，不是 T3 的蓝。
5. **每个字符串进 `mobile/ui/i18n.ts`，英文和简体中文**（与桌面同一条规矩）。
   样稿用中文。

### 字体

- 西文照 T3 用 **DM Sans**，只三档：Regular、Medium、Bold（OFL 许可，
  `registerFont` 随 app 带）。带的文件的字族名是 **"DM Sans 9pt"**（NSH 先认
  nameID 16），`nsh.json` 的 `font-sans` 要先写它，只写 "DM Sans" 就落到了系统
  字体。**中文** DM Sans 没有，退到系统的（苹方、Noto Sans CJK、微软雅黑）。
- 代码、分支名、时间、项目字标：系统等宽（SF Mono / Menlo / Roboto Mono）。
- 跳动的计时用系统字体加粗、等宽数字（DM Sans 没有等宽数字）。

| 角色 | 字号 / 行高 | 用在 |
| :-- | :-- | :-- |
| micro | 11 / 14 | 滑动操作的标签 |
| caption | 12 / 16 | 代码、小标题（大写） |
| label | 13 / 17 | 元信息、状态字 |
| footnote | 14 / 19 | 工具行、说明 |
| body | 16 / 23 | 列表标题、对话正文 |
| headline | 18 / 23 | 导航栏标题（Bold） |
| title | 21 / 28 | 空状态标题 |
| largeTitle | 26 / 32 | 新任务的大标题 |

### 间距、圆角、阴影

- 4pt 网格。列表行左右 20、上下 10；分组列表左右缩 20、组间 14；卡片内距 16；
  输入框外距 12。
- 圆角：分组 24、提示 28、毛玻璃 32、输入框胶囊 27、审批和提问卡片 20、用户
  气泡 20、配对卡片 26、选项按钮和筛选 16、图片 14、diff 文件头 10、代码块 8；
  按钮和胶囊全圆。
- 边框 1px；行分隔线 1px，左边缩 20。
- 阴影只给浮起来的：输入框 `0 6 28` 黑 15%（深色 35%）；毛玻璃 `0 14 28` 黑
  8%（深色 22%）。
- 毛玻璃：浮起来的圆钮、筛选胶囊和 TabBar 带 `glassEffect: "regular"`，iOS
  26 上是 Liquid Glass；别处退到 `backdropFilter: blur(20px)` 加半透明底和 1px
  边框。

### 图标

- **Lucide**（pansy 窗口已在用，ISC），对应 T3 的 SF Symbols；常用大小：箭头
  和状态 12、筛选 15、列表 22、发送圆钮里 18。
- **agent 的品牌图标**用 `desktop/ui/logos/` 里的（Claude Code、Codex、Gemini
  CLI……），单色显示，Claude 保留它的橙 `#D97757`，照 T3。
- 项目图标：照 T3 的字标。两个等宽大写字母：第一个词的首字母，再加它的第一个
  数字，没有就取最后一个词的首字母，只有一个词就取它自己的末字母（pansy → PY、
  pansy-site → PS、nsh2 → N2）。颜色是按名字哈希（`(i*31+码点)%18`）挑的
  Tailwind 500 色，底是它的 15%，圆角 25%。

### 动效和触感

照 T3 的 `MOBILE_MOTION`：调整 120ms、进入 200ms、退出 150ms；新回答淡入
220ms；展开收起 180ms；审批卡片从下淡入 200ms。尊重系统的"减弱动态效果"。

触感（NSH `Haptics`）：展开、复制、切换用 `selection`；流式输出每 320ms 最多
一下 `selection`；滑到底触发操作用 `medium`；成功、失败用 `notification`。

```
│                              ├─ 模型（底部弹出）
│                              ├─ 线程设置（底部弹出：权限模式、plan 模式）
│                              └─ 排队（底部弹出）
├─ PR    ── PR 列表 ── PR 页（二期）
├─ 用量  ── pansy 的用量（二期）
└─ 设置  ── 机器 ── 一台机器（路由、权限、设备批准）
           ├─ 账号（登录、绑定）
           ├─ 通知、外观、语言、工作树清理
           └─ 关于

全局弹出：添加机器（配对）、新任务、登录
```

- 页面用 NSH 的 `NavStack` 和系统导航栏：**不用大标题**，标题 18pt Bold；返回
  只有箭头没有字；内容从导航栏下面滚过。
- 弹出用 `Sheet`，有把手，两个停靠高度：起始高度和全屏。起始高度照 T3：Git
  0.55、提交 0.8、模型 0.6、配对 0.55、排队 0.65。弹出只能关，不能"返回"。
- TabBar 照 T3 浮在底部：一个毛玻璃胶囊装四个只有图标的标签（选中的有一层
  浅底、用强调色），右边隔开一个 62pt 的毛玻璃圆钮是**新任务**（没有机器时是
  添加机器）。一期四个标签都在：对话、设置能用，PR、用量灰掉（35% 不透明），
  二期再开。TabBar 是 app 自己画的，不用 nsh/mobile 的 `TabBar`：那个在 web
  上什么都不画，也画不出旁边的新任务圆钮。
- **平板和桌面浏览器**（`horizontalSizeClass` 为 regular）：左边线程列表、右边
  线程，弹出改成居中的对话框。
- **Web 版**没有系统导航栏，由 app 自己画同样的头（NSH 的 `header`）。

## 页面

### 1. 对话（线程列表）

自上而下：

1. **头。** 左：pansy 的花形标志 + "pansy"（21pt Medium，次要色，字距 −0.5）。
   右：只有搜索，一个 44pt 毛玻璃圆钮（新任务在 TabBar 旁边）。**没有一台机器
   在线**超过 800ms 时，标题位置换成转圈和"正在重新连接到 家里的 Mac"（几台
   时"正在重新连接 2 台机器"），连不上的换成 `wifi-off` 和"未连接"，照 T3。
2. **筛选。** 一排横滑的毛玻璃胶囊：全部机器 ▾、全部项目 ▾、全部 agent ▾
   （pansy 多的一个）。选中的填强调色；有选中的时，后面一个 `circle-x` 一下全
   清掉。
3. **分区**（照 T3 的书架）：
   - 进行中（含置顶、未发出）在最上面，**没有分区头**；
   - 已暂缓（稍后到时间前的），默认收起；
   - 已收尾（pansy 的已归档），默认展开，先显示 10 条，底下一个虚线框的
     "显示更多（已隐藏 N 个已收尾）"，每按一下多 25 条；换筛选或搜索时回到 10。
   分区头是 12pt Medium 第三色的字，后面一条细线到头，再一个可转的小箭头；收起
   时写"已收尾 (12)"。T3 的线程 7 天不动会自动收尾，pansy 还没有（要协议支持）。
4. **行**（左右 20、上下 10）：
   - 第一行：项目字标、标题（16 Medium，最多两行），右边是状态（图标 + 13pt
     加粗字 + 计时）或时间（等宽、紧凑："<1m"、"5m"、"3h"、"2d"）；置顶时一个
     小图钉。
   - 第二行（13pt 第三色）：机器名 · 分支（等宽）· agent 图标 + **模型名**
     （pansy 的，如 `deepseek/v4`）· PR 标记（`#16`，带颜色图标）· `+42 −7`。
   - 失败时第二行换成红色的错误一句话。
   - 进行中和等待中的整行淡到 55%。
   - 已暂缓和已收尾的行是 44pt 单行：字标 40%、标题常规次要色、右边等宽时间。
5. **左滑**：收尾（主，蓝色圆）、暂缓（次，灰色圆，弹出时间菜单）；滑到底直接
   收尾，带触感。长按是系统菜单：置顶、改名、标为未读、复制链接、删除线程记录。
6. **搜索**：下拉出搜索框（一期只搜标题，二期搜内容，pansy 已有
   `sessions::search`）。
7. **空状态**：没有机器时，居中"连一台电脑"+ 说明 + "添加机器"按钮；有机器
   没线程时，"在 {机器} 上开一个任务"。

终端里开过、还没被 pansy 接管的会话也在列表里，显示成普通的行，第二行多一个
"终端"小字；点开就是只读历史加输入框，发出第一句时才续接。

### 2. 线程

- **头**：标题；副标题"项目 · 机器"，重连时换成"正在重连…"。右边：Git
  （`git-branch`）、改动（`file-diff`，带 `+N −N`）、更多（`ellipsis`：改名、
  分叉、复制、收尾、在电脑上打开）。
- **用户的话**：右对齐气泡，圆角 20，`bubble` 底，最宽 85%，内距 14×10；下面
  右对齐时间和复制。
- **agent 的回答**：平铺的 Markdown（标题、列表、表格、代码块带复制和语言名、
  行内代码）；下面：复制、从这里分叉、时间；这一回合改了文件就加 `+N −N`，点开
  是这回合的 diff。
- **工作记录**（工具调用、命令、读写文件）：一行 28pt，24×24 图标位、一句 14pt
  次要色的描述（"读了 run.rs"、"跑了 cargo test"、"改了 3 个文件"）、小箭头。
  点开缩进 28，最高 240pt 内部滚动，命令和输出 12pt 等宽。正在跑的行有扫光；
  危险的（删文件、`rm`）用 rose；额度用尽用 amber。连续的工具行合成一组
  "用了 6 个工具"，可展开。
- **思考**：折叠成"思考了 12 秒"，展开最高 384pt，底部渐隐。
- **子 agent**：6pt 状态点、名字、`agent · 模型`、箭头，点开是它自己的记录。
- **状态胶囊**（浮在输入框上方，44pt 毛玻璃）：状态（进行中 + 计时 / 已停止）
  │ 排队 N │ 子 agent N；旁边一个回到底部的圆钮。
- **审批卡片**（停在输入框上方，不在对话流里）：
  - 小标题"需要批准"（12pt Bold 大写、字距 1.1、次要色）；
  - 标题（18 Bold）："运行命令" / "修改 3 个文件" / "访问网络"；
  - 内容：命令（等宽，最多 4 行可展开）或文件列表（带 `+N −N`，点开看 diff）；
  - agent 给的理由（13pt warning 色）；
  - 按钮，全宽、全圆、48pt、上下间隔 8："允许这一次"（强调色）、"本会话都
    允许"（次要）、"拒绝"（淡红底红字）。Codex 给的"总是允许"等选项照它给的
    显示。
  - 这时输入框的占位字变成"发一句话拒绝，并告诉 agent 该怎么做"。
  - 同时有几个审批时，卡片右上角"1 / 3"，左右滑。
- **提问卡片**（agent 问用户）：小标题"需要回答"，每个问题一组选项按钮（最少
  48pt、圆角 16、选中时强调色边框和 10% 底）、可以写"其他"；底部"提交回答"
  和文字按钮"不回答"。可收成一个胶囊。
- **计划卡片**（plan 模式，二期）：计划的 Markdown，"按这个计划做" / "再改改"。

### 3. 输入框

- 浮在对话上，后面一层从透明到画布色的渐变。毛玻璃胶囊，圆角 27。
- 一行，每个控件 44pt：`+`（附件：照片、文件，二期）│ 输入区（占位"让它做点
  什么"）│ **模型胶囊**│ 麦克风（二期）│ 发送（30pt 强调色圆，`arrow-up`）。
- 模型胶囊：收起时只有 agent 图标和模型短名（`v4`）；点开是模型弹出层。
- 回合进行中：发送变成"插话"（`corner-left-up`）或"排队"（`list-ordered`），
  长按换另一个；旁边一个红色的停止圆钮（`square` 实心），再按一次是强制停止。
- 键盘上方一条（NSH `InputAccessoryView`）：权限模式胶囊（"完全访问" ▾）、
  plan 模式开关、`@` 文件（二期）、`/` 命令（三期）。

### 4. 模型（底部弹出，pansy 多出来的）

- 顶上：这个线程的 agent（图标 + 名字），以及"只换这个线程"的说明。
- 搜索框。
- 分组列表：
  - **路由组**（pansy 的 `group/…`）：名字、成员数、走法（依次 / 轮流 / 最少
    用）。
  - **按 provider**：每个 provider 一组（它的图标），下面是模型：名字、上下文
    窗口、看图 / 推理的小图标、剩余额度条（订阅的）。
  - **agent 自己的**（Codex 用 ChatGPT 登录时的模型等），放最后。
- 选中的打勾。下面一行"推理强度"分段控件（低 / 中 / 高 / 超高），agent 支持
  时才出现。
- 换模型在下一回合生效，弹层底部说明这一句。

### 5. 线程设置（底部弹出）

- 权限模式，四个单选，照 T3 的名字和说明：
  - 每次询问（Supervised）：命令和改文件都要批准；
  - 自动接受编辑：改文件自动，其余要批准；
  - 自动：用 agent 自己的审查，常规的自动；
  - **完全访问**（默认）：不问。
  - agent 不支持的不显示，例如 Muse 只有两种。
- plan 模式开关。
- 工作区：当前分支 / 工作树路径（只读，等宽）。

### 6. Git（底部弹出，0.55）

- 标题：分支名（等宽）；副标题："领先 2 · 3 个文件未提交"。
- 一个分组（圆角 24，`grouped` 底），每行至少 56pt：22pt 图标、16 字、14 次要
  说明：
  - **提交并推送**（主操作，用 `prominent` 反色胶囊按钮放在分组上方，48pt，
    右边一个下拉：只提交 / 只推送 / 提交、推送并开 PR）；
  - 开 PR（没有 PR 时）或"PR #16 · 检查 3/4 通过"（有 PR 时，点进 PR 页）；
  - 拉取最新；
  - 查看改动；
  - 分支和工作树（二期）；
  - 合回 `main`（工作树线程，二期）。
- 在默认分支上时，主按钮上方一条 warning 提示"你在 main 上"，按下要再确认。

### 7. 提交（底部弹出，0.8）

- 说明输入框（至少 96pt，圆角 12，`grouped` 底），占位"不填就由 {模型} 来写"；
  右下一个"生成"小按钮，立刻用网关写一句填进来。
- 改动的文件：每行至少 64pt，勾选框、路径（等宽，目录淡）、`+N −N`；顶上
  "全选 / 全不选"。
- 选项：推送；开 PR（开了就多两行：标题、目标分支）。
- 底部主按钮："提交 3 个文件"。
- 按下后弹层变成进度：分支 → 提交 → 推送 → PR，每步一个勾或叉，hook 的输出
  可展开；PR 开好后给出链接和"在浏览器打开"。

### 8. 改动（全屏弹出）

- 顶上分段控件：本回合 / 最近回合 / 未提交 / 全部（相对基线）。
- 文件列表（可收起）：路径、状态字（新增 / 修改 / 删除 / 改名）、`+N −N`。
- diff：一行 22pt，46pt 行号槽，代码 12pt 等宽、行号 11pt；新增行和删除行的底
  色、左边 4px 色条、hunk 头的颜色照 T3（浅色新增底 `#d9f0eb`、删除底
  `#f5d9e6`，深色 `#05291a` / `#2e0d14`）。横向可滚，不折行。
- 长按选中几行，底部浮出"评论"胶囊：评论连同这几行进输入框，发给 agent。

### 9. 新任务（全屏弹出）

- 居中的大标题（26pt Medium，字距收紧）："在 **pansy** 里做点什么？"，项目名带
  下划线，点开换项目。
- 下面一排胶囊：机器 ▾ · agent ▾ · 模型 ▾ · 工作区 ▾（当前分支 / 新分支 / 新
  工作树，选工作树时再选基线分支）。
- 输入框在底部，和线程里的一样。发出就建线程、跳进去。

### 10. 添加机器（配对，底部弹出 0.55）

一期 NSH 没有相机，所以和 T3 的不同在第一块：

- **"用相机扫电脑上的二维码"**卡片（250pt、圆角 26、径向渐变底，照 T3 的
  样子）：一期在 iOS 和 Android 上点它提示"用系统相机扫，会自动打开 pansy"；
  Web 版就是用系统相机扫码打开的页面本身，直接进入下一步。以后有了相机模块
  改成取景框。
- "或者手动输入"：分组卡片两行，地址（`192.168.1.20:7268`）和配对码，每行
  52pt、左边 80pt 宽的标签。
- 出错时卡片红边，下面一句红字。
- 连上后：机器名、它的 agent 图标一排、"已连上"，再"完成"。
- **已登录账号时**，这一页顶上多一块"你账号下的电脑"列表，点一下就连（设备
  批准开着时，显示短码和"在电脑上批准"）。

### 11. 登录（全屏弹出）

- pansy 标志、"登录 pansy"、一句说明："登录后，手机能找到你账号下的电脑，并
  收到推送。不登录也能在家里扫码连。"
- 按钮（全宽、全圆、48pt，上下 8）：**用 Apple 登录**（黑底白字，Apple 的规定
  样式）、用 Google 登录、用 GitHub 登录；分隔线"或"；邮箱输入框、"发送验证码"。
- 验证码页：6 个格子（`textContentType: one-time-code`，iOS 能从短信 / 邮件
  自动填），下面"或者点邮件里的链接"——手机在这页等着，链接在哪台设备上点开
  都会登进来；"重新发送"倒计时。
- 底部小字：隐私政策、条款。大陆网络下 Google 和 GitHub 不通时，不隐藏按钮，
  点了失败给一句"这个网络连不上 Google，试试邮箱或 Apple"。

### 12. 设置

- **机器**：每台一行（名字、在线点、系统、pansy 版本），点进：
  - 路由：有序列表（局域网、Tailscale、隧道），每条的地址和最近一次是否连通，
    可拖动排序、添加；
  - 你的权限：范围列表（只读显示）；
  - 设备批准开关（有 `access:write` 时）；这台电脑上的其他设备，可吊销；
  - 移除这台机器。
- **账号**：头像、邮箱、已绑定的登录方式、绑定其他方式、退出、删除账号。
- **通知**：推送开关（等审批、等回答、完成、失败四项），没有原生推送时说明
  "用 Web 版加到主屏幕可以收推送，或者填一个 ntfy / Bark 地址"。
- **外观**（跟随系统 / 浅 / 深）、**语言**（跟随系统 / English / 简体中文）。
- **工作树清理**（二期）：照 T3 的策略。
- **关于**：版本、许可、开源组件。

### 13. 状态和反馈

- **加载**：不用骨架屏，照 T3：居中转圈加一句 18 Bold；顶上 4px 的进度条；
  系统下拉刷新。
- **离线**：不弹横幅，照 T3 放在头的标题或副标题和状态胶囊里。
- **出错**：红边红底的提示卡（圆角 16），一句话加"重试"。
- **撤销提示**：毛玻璃、圆角 28，`circle-check` + 一句 + "撤销"，可滑走
  （NSH `Toast`）。
- **未发出**：离线时发的话留在本地，气泡下一行"未发出 · 重试"，列表里进
  "未发出"分区（二期）。

## 桌面窗口：设置 › 共享与访问

手机要配对，电脑这一侧也要有地方：

- 总开关"允许其他设备控制这台电脑"，下面一句红字说明"配对过的设备能在这台
  电脑上做任何事"。
- **配对**：按钮"添加设备"→ 一个对话框，二维码（`https://<局域网地址>/pair#…`）
  和链接、10 分钟倒计时、可选"只读"。
- **设备**：每台一行（名字、系统、最近连接、范围），吊销。
- **待批准**（设备批准开着时）：短码、设备名、批准 / 拒绝。
- **路由**：局域网地址、Tailscale 地址（检测到时）、隧道（登录后可开）。
- **账号**：登录 / 已登录的邮箱。
- **服务**：pansy 是否装成了后台服务，没装时"安装"按钮（关窗口不影响手机）。
